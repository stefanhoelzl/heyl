# heyl-domain

heylogin's domain vocabulary and key hierarchy: identifiers, lock structures,
heymerge-compatible timestamps, and the authenticator → profile → vault chain.

**Internal to [`heyl`](https://github.com/stefanhoelzl/heyl). No API stability
guarantee.**

Pure and I/O-free: no runtime, no transport, no OS. `unsafe_code = "forbid"`.
